# Стек

[Стек] представляет собой структуру данных LIFO (Last In, First Out). 
Необходимо реализовать класс `Stack`, который представляет собой простую обертку
над контейнером `std::vector<int>`. 

Класс предоставляет следующие методы:

- Метод `Push` - добавляет элемент на верхушку стека
- Метод `Pop` - убирает элемент с верхушки стека
- Метод `Top` - обеспечивает доступ на запись и чтение к элементу на верхушке стека
- Метод `Empty` - возвращает результат проверки стека на отсутствие элементов  
- Метод `Size` - возвращает количество элементов в стеке
- Метод `Clear` - очищает стек
- Метод `Swap` - обменивается элементами с другим стеком (без копирования)
- Оператор `==` - сравнение стеков на равенство
- Оператор `!=` - сравнение стеков на неравенство

Вызов метода `Pop` от пустого стека является корректной операцией. Метод должен 
возвращать `true` или `false` в зависимости от того, выполнялась операция или нет.

## Примечание

- Запрещено использовать класс `std::stack`
- Значения стека должны находиться в закрытой части класса
- Рекомендуется определять методы вне класса
- Некоторые методы могут потребовать перегрузки
- Обратите внимание, что при использовании в качестве полей контейнеров стандартной
  библиотеки нет необходимости писать собственные специальные методы
